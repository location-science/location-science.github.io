# Daten- und Werkzeugnachweise

Diese Seite nennt die Datenquellen und Werkzeuge, die in unserem Produkt verwendet werden, mit ihren Lizenzen und Nennungspflichten.

## OpenStreetMap

Unser Produkt verwendet Daten von OpenStreetMap®, offene Daten unter der Open Data Commons Open Database License (ODbL) der OpenStreetMap Foundation (OSMF).

### Erforderliche Nennung
© OpenStreetMap-Mitwirkende

### Lizenzbedingungen
- Sie dürfen die Daten kopieren, verbreiten, übermitteln und anpassen.
- Sie müssen OpenStreetMap und seine Mitwirkenden nennen.
- Wenn Sie die Daten verändern oder darauf aufbauen, dürfen Sie das Ergebnis nur unter derselben Lizenz weitergeben.
- Der vollständige Lizenztext: [Open Data Commons Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/)

### So wird genannt
Bei Verwendung von OpenStreetMap-Daten müssen Sie:
1. den Urheberrechtshinweis „© OpenStreetMap-Mitwirkende“ anzeigen;
2. deutlich machen, dass die Daten unter der Open Database License stehen;
3. auf die Urheberrechtsseite von OpenStreetMap verlinken: [www.openstreetmap.org/copyright](https://www.openstreetmap.org/copyright).

## Wikipedia und Wikidata

Unser Produkt verwendet Daten aus Wikipedia und Wikidata, lizenziert unter der Creative Commons Attribution-ShareAlike 3.0 Unported License (CC BY-SA 3.0).

### Erforderliche Nennung
Inhalte aus Wikipedia und Wikidata stehen unter der Creative Commons Attribution-ShareAlike 3.0 Unported License.

### Lizenzbedingungen
- Sie dürfen die Inhalte teilen und bearbeiten.
- Sie müssen angemessene Urheber- und Rechteangaben machen.
- Sie müssen Ihre Beiträge unter derselben Lizenz weitergeben.
- Sie dürfen keine zusätzlichen Klauseln oder technischen Verfahren einsetzen, die anderen rechtlich untersagen, was die Lizenz erlaubt.

### So wird genannt
Bei Verwendung von Inhalten aus Wikipedia oder Wikidata müssen Sie:
1. die ursprünglichen Autoren nennen;
2. auf die Lizenz verlinken: [Creative Commons Attribution-ShareAlike 3.0 Unported License](https://creativecommons.org/licenses/by-sa/3.0/);
3. angeben, ob Änderungen vorgenommen wurden;
4. Ihre Beiträge unter denselben Bedingungen lizenzieren.
